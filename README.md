# Cornell CS Major Planner

This project allows users to track their progress in Cornell University's Computer Science curriculum (designed for A&S students).

# Features:
Login authentication, list of courses and their corresponding sections (Intro Computing, Math, Core CS, etc.), 
course descriptions, prerequisites/corequisites, course outcomes, etc.
Users can toggle to add / remove courses from their "completed" list, and the app will inform them of whether or not all requirements 
for a particular section have been completed.
